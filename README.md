# Little storybooks

Create personal storybooks on your Mac with family characters, photos, original story starts and reviewed AI suggestions. Read saved versions and print or save PDF in English or Turkish. Works without AI. Photo-reference drawing requires the matching Tellop service and Mac release. Protected online reading is not available yet.

This app was made with Tellop, the app builder by Pathnomic Labs, on Tellop's
starting kit: Next.js and React, with Node's own SQLite for what the app keeps.
It is published under the Apache License 2.0 (`LICENSE`).

## Use it with Tellop

The app's working features need a compatible version of Tellop on a Mac.
Installing and running this source directly outside Tellop only shows
unavailable screens. It does not enable the app's working features.

Tellop manages the app's saved records, photos and files. These personal
records and files are not part of this repository. This app does not provide
its own private sign-in or online hosting.
